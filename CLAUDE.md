# Buildio.au Theme

Main Buildio website (buildio.au). Uses the custom theme: `public_html/wp-content/themes/buildio2/`

Everything outside this directory is standard WordPress — ignore it.

- **Local domain**: bdoau.local.site
- **Production domain**: buildio.au
- **Hosting**: InterServer (vda4300.is.cc), DirectAdmin, SSH user `buildiod`
- **Deployment**: rsync via `_deploy/deploy_all_LIVE.sh` from WSL/Ubuntu
